# Pharmacy Billing Requests & Payments APIs

These endpoints manage patient billing requests generated by the pharmacist, patient lookups, and the clearing/payment of bills.

---

## 1. Create Billing Request
* **Endpoint:** `POST /api/pharmacy/request`
* **Role required:** `PHARMACY`
* **Content-Type:** `application/json`

### Description
Creates a pending billing request for items/drugs. The backend checks the hospital config:
* If `allow_pharmacy_walk_in` is `false`, a valid registered hospital patient ID is **required**.
* If `allow_pharmacy_walk_in` is `true`, a patient ID is optional. If not provided (or set to `'MANUAL'`), the request is treated as a walk-in, and `patient_name` and `phone_number` are required.

### Request Body
```json
{
  "patient_id": "1002",
  "patient_name": "Alice Johnson",
  "phone_number": "08098765432",
  "items": [
    {
      "pharmacy_item_id": "e671a2e-4b2a-4dfa-8a5e-b49cb4a52444",
      "quantity": 10
    }
  ]
}
```

### Expected Response (`201 Created`)
```json
{
  "status": 201,
  "message": "Pharmacy billing request created successfully",
  "data": {
    "id": "a9821a2e-4b2a-4dfa-8a5e-b49cb4a52555",
    "billing_code": "PH-98765432",
    "patient_id": "1002",
    "patient_name": "Alice Johnson",
    "phone_number": "08098765432",
    "total_amount": 55.00,
    "status": "pending",
    "items": [
      {
        "pharmacy_item_id": "e671a2e-4b2a-4dfa-8a5e-b49cb4a52444",
        "quantity": 10,
        "unit_price": 5.50,
        "total_price": 55.00,
        "item_name": "Paracetamol 500mg"
      }
    ]
  }
}
```

## 2. List Billing Requests
* **Endpoint:** `GET /api/pharmacy/request`
* **Role required:** `PHARMACY` or `PLATFORM_ADMIN`
* **Query Parameters:**
  * `status` (optional, string): Filter by request status (`'all'`, `'pending'`, `'dispensed'`, `'cancelled'`). Default is `'all'`.
  * `start_date` / `end_date` (optional, string): Filter requests by date (`YYYY-MM-DD`).
  * `page` (optional, integer): Page number. Default is `1`.
  * `limit` (optional, integer): Records per page. Default is `30`.

### Expected Response (`200 OK`)
Returns paginated list of billing requests matching the properties returned during creation.

---

## 3. Retrieve Single Request Details
* **Endpoint:** `GET /api/pharmacy/request/:requestId`
* **Role required:** `PHARMACY` or `PLATFORM_ADMIN`

### Expected Response (`200 OK`)
Returns complete request details including nested items array.

---

## 4. Edit Pending Billing Request
* **Endpoint:** `PATCH /api/pharmacy/request/:requestId`
* **Role required:** `PHARMACY`
* **Content-Type:** `application/json`

### Description
Allows editing patient details (`patient_name`, `phone_number`) or modifying the items list (adding/removing items or changing quantities) of a **pending** billing request.

### Request Body
Same schema as the creation body. All parameters are optional.

---

## 5. Cancel Billing Request
* **Endpoint:** `PATCH /api/pharmacy/request/:requestId/cancel`
* **Role required:** `PHARMACY`

### Description
Cancels a pending billing request. Once cancelled, it cannot be paid or processed.

### Expected Response (`200 OK`)
```json
{
  "status": 200,
  "message": "Pharmacy billing request cancelled successfully",
  "data": {
    "id": "a9821a2e-4b2a-4dfa-8a5e-b49cb4a52555",
    "status": "cancelled"
  }
}
```

---

## 6. Pharmacist Self-Pay / Direct Clear
* **Endpoint:** `POST /api/pharmacy/request/:requestId/pay`
* **Role required:** `PHARMACY`
* **Content-Type:** `application/json`

### Description
Allows pharmacists to accept cash directly from patients and clear the billing request. **Note:** This is only allowed if `allow_pharmacy_self_pay` is enabled for the hospital.
* Reduces database inventory stock counts of the dispensed drugs.
* Creates a completed record in the general `transactions` table under the `"Pharmacy"` department.

### Request Body
```json
{
  "payment_type": "cash" 
}
```
* **Supported values:** `"cash"`, `"transfer"`, `"pos"`. Default is `"cash"`.

### Expected Response (`200 OK`)
```json
{
  "status": 200,
  "message": "Pharmacy bill cleared successfully",
  "data": {
    "receipt_no": "REC-7762512",
    "billing_code": "PH-98765432",
    "patient_name": "Alice Johnson",
    "amount": 55.00,
    "payment_type": "cash",
    "status": "completed",
    "created_at": "2026-07-22T06:15:00.000Z"
  }
}
```

## 7. Walk-In Patient Lookup
* **Endpoint:** `GET /api/pharmacy/walk-in/:phoneNumber`
* **Role required:** `PHARMACY`

### Description
Verifies if a walk-in patient with the specified phone number has previously purchased items at this hospital's pharmacy. If yes, it returns their name to auto-fill the frontend form.

### Expected Response (`200 OK`)
```json
{
  "status": 200,
  "message": "Walk-in patient lookup completed successfully",
  "data": {
    "patient_name": "Alice Johnson"
  }
}
```
If not found, `data` is `null`.
