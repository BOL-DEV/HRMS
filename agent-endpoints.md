# Cashier/Agent Module API Integration Guide

This document lists the API endpoints consumed by each sub-module/page within the Cashier/Agent module.

---

## Global Requirements
All endpoints in this module require the following headers:
* `Authorization: Bearer <token>`
* Role: `AGENT`

---

## 1. Agent Profile (Global Context)
* **Endpoint:** `GET /api/agent/profile`
* **Description:** Retrieves the agent profile, wallet balance, and assigned hospital settings.

---

## 2. Dashboard Sub-module (`/agents/dashboard`)
* **Endpoint:** `GET /api/agent/dashboard?time_period=<period>`
  * **Description:** Retrieves cashier-specific daily, weekly, or monthly analytics (total transaction count, total collections, wallet status, etc.).
* **Endpoint:** `GET /api/agent/profile`
  * **Description:** Accesses active wallet balance and personal details.

---

## 3. Transactions / Payment Checkout Sub-module (`/agents/transactions` & New Payment flow)
Provides form tools to search catalog items, lookup patients, and process standard or express bill checkouts.
* **Endpoint:** `GET /api/agent/departments`
  * **Description:** Lists hospital departments for category lookup.
* **Endpoint:** `GET /api/agent/payment-config`
  * **Description:** Retrieves active checkout payment options configured for the hospital.
* **Endpoint:** `GET /api/agent/patients/:patientId`
  * **Description:** Looks up a registered patient by their patient ID digits.
* **Endpoint:** `GET /api/hospitals/:hospitalId/patients/search`
  * **Description:** Queries patient directory by name or numeric characters.
* **Endpoint:** `GET /api/agent/income-heads`
  * **Description:** Lists active income categories.
* **Endpoint:** `GET /api/agent/bill-items`
  * **Description:** Searches billable catalog items.
* **Endpoint:** `POST /api/payments/process`
  * **Description:** Processes checkout payment for a registered patient.
* **Endpoint:** `POST /api/payments/express/process`
  * **Description:** Processes express checkout payment for a walk-in patient (without registration ID).
* **Endpoint:** `GET /api/payments/pharmacy-requests`
  * **Description:** Queries pending pharmacy billing requests (by `billing_code` or `patient_id`) to pull prescription items.
* **Endpoint:** `POST /api/payments/pharmacy/process`
  * **Description:** Processes checkout payment for a pharmacy billing request.

---

## 4. Receipts Sub-module (`/agents/receipts`)
* **Endpoint:** `GET /api/agent/receipts`
  * **Description:** Retrieves list of receipts generated by the cashier.
* **Endpoint:** `POST /api/agent/receipts/request-reprint`
  * **Description:** Dispatches reprint authorization request to FO.
* **Endpoint:** `POST /api/agent/receipts/print-approved`
  * **Description:** Fetches print-ready payload for approved receipt reprints.

---

## 5. Reports Sub-module (`/agents/reports`)
* **Endpoint:** `GET /api/agent/transactions`
  * **Description:** Retrieves historical list of payments processed by the agent.

---

## 6. Topup History Sub-module (`/agents/topup-history`)
* **Endpoint:** `GET /api/agent/topup-history`
  * **Description:** Retrieves history of wallet top-ups/allocations assigned to the agent account.
